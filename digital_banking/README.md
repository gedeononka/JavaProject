Projet Bank_java
Description
Le projet Bank_java est une application bancaire développée en Java qui utilise JavaFX pour l'interface graphique, MySQL pour la gestion de la base de données, et implémente l'architecture MVC (Modèle-Vue-Contrôleur) pour séparer les différentes responsabilités du projet.

Fonctionnalités :
Gestion des comptes bancaires (création, consultation, modification, suppression)
Transactions entre comptes (dépôts, retraits, virements)
Affichage dynamique de l'état des comptes
Système de connexion sécurisé pour les utilisateurs
Technologies utilisées
Langage : Java
Interface graphique : JavaFX
Base de données : MySQL
Architecture : MVC (Modèle-Vue-Contrôleur)
IDE : IntelliJ IDEA
